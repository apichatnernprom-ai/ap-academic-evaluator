# ระบบตรวจสอบผลงานวิชาการก่อนส่งประเมินวิทยฐานะครูเชี่ยวชาญ (สอศ.)

🌐 **เว็บไซต์ออนไลน์ (Live Demo):** [https://ap-academic-evaluator.vercel.app](https://ap-academic-evaluator.vercel.app)

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fapichatnernprom-ai%2Fap-academic-evaluator)

เว็บแอปพลิเคชันสำหรับการตรวจสอบความพร้อมและตรวจประเมินผลงานวิชาการก่อนส่งประเมินวิทยฐานะครูเชี่ยวชาญ สังกัดสำนักงานคณะกรรมการการอาชีวศึกษา (สอศ.)

## 🌟 ฟังก์ชันการทำงานหลัก

### 1. ระบบตรวจสอบผลงานวิชาการก่อนส่งประเมินวิทยฐานะครูเชี่ยวชาญ (index.html)
- **ระบบสแกนเอกสารอัตโนมัติ (Automated Document Inspection):**
  - รองรับไฟล์เอกสาร `.docx` (Word), `.pdf`, และ `.txt`
  - ตรวจจับคำสำคัญ (Keywords) ทางวิชาการ เช่น R&D, ความตรงเชิงเนื้อหา (IOC), ความเชื่อมั่น (Reliability), แผนการสอน, APA 7, ระเบียบวิธีวิจัย และสถิติ
- **รายการตรวจสอบ 6 ส่วนหลัก รวม 119 ข้อ:**
  - ส่วนที่ 1 ด้านแนวคิดและลักษณะของงานวิจัย (R&D และความเชื่อมโยงเชิงสาเหตุ)
  - ส่วนที่ 2 ด้านระเบียบวิธีวิจัยและเครื่องมือ (แบบแผนวิจัย, คุณภาพเครื่องมือ, การวิเคราะห์ข้อมูล)
  - ส่วนที่ 3 ด้านเนื้อหาและการเขียนรายงานวิจัย (บทที่ 1 ถึง บทที่ 5)
  - ส่วนที่ 4 ด้านรูปแบบและการนำเสนอ (องค์ประกอบ, ภาษา, การอ้างอิง APA 7, ภาคผนวก)
  - ส่วนที่ 5 ด้านจริยธรรมและความถูกต้อง (การป้องกันการคัดลอก, จรรยาบรรณวิจัย)
  - ส่วนที่ 6 ด้านผลลัพธ์และการนำไปใช้ (ผลสัมฤทธิ์ผู้เรียน, การขยายผล)
- **Final Check 15 จุดเสี่ยงสูง:** ตรวจทานจุดวิกฤตที่คณะกรรมการผู้ทรงคุณวุฒิใช้เป็นเกณฑ์ตัดสิน
- **Real-time Scoring & Dashboard:** คำนวณเปอร์เซ็นต์ความพร้อมและประเมินระดับความพร้อม 4 ระดับ
- **Auto-Save & Print / Export PDF:** บันทึกข้อมูลสถานะลง LocalStorage และมีแบบฟอร์มคำรับรองการตรวจสอบพร้อมพิมพ์

### 2. ระบบประเมินคุณภาพงานวิจัยในชั้นเรียน สำหรับศึกษานิเทศก์และครูผู้สอน (classroom-research.html)
- **เกณฑ์ประเมินมาตรฐาน สอศ.:** ครอบคลุม 19 หัวข้อ 29 ตัวชี้วัด (เต็ม 87 คะแนน)
- **ระบบประเมินอัจฉริยะ Dual-Engine:**
  - รองรับ Google Gemini API และ Built-in Thai Academic Heuristic Analysis Engine
- **กล่องสรุปจุดที่ต้องแก้ไขเร่งด่วน (Urgent Improvement Recommendations):** ชี้เป้ารายการที่อยู่ในเกณฑ์ "ควรพัฒนา" (1 คะแนน) พร้อมให้คำแนะนำเชิงรูปธรรม
- **การตัดเกรดเหรียญรางวัลมาตรฐาน สอศ.:**
  - เหรียญทอง (ยอดเยี่ยม): ร้อยละ 80 ขึ้นไป
  - เหรียญทอง (ดีเลิศ): ร้อยละ 70 - 79.99
  - เหรียญเงิน (ดี): ร้อยละ 60 - 69.99
  - เหรียญแดง (ปานกลาง): ร้อยละ 50 - 59.99
  - ต้องปรับปรุง: น้อยกว่าร้อยละ 50
- **ตารางประเมิน Interactive & Print View:** ศึกษานิเทศก์สามารถปรับคะแนน (1-3) และกรอกข้อสังเกตได้แบบ Real-time พร้อมโหมดพิมพ์แบบฟอร์มประเมินทางการของ สอศ. พร้อมช่องลงลายมือชื่อ

## 🚀 การ Deploy บน Vercel

โครงการนี้สร้างด้วย HTML/CSS/Vanilla JavaScript (Tailwind CSS, Font Awesome, Lucide Icons, Mammoth.js, PDF.js) ซึ่งเป็น Static Web Application สามารถ Deploy บน Vercel ได้ทันทีโดยไม่ต้องตั้งค่า Build Command

### วิธีที่ 1: Deploy ผ่าน GitHub (แนะนำ)
1. Push โค้ดนี้ขึ้น GitHub Repository
2. ไปที่ [vercel.com](https://vercel.com) แล้วเข้าสู่ระบบ
3. คลิก **"Add New..."** -> **"Project"**
4. เลือก GitHub Repository ของคุณ แล้วกด **"Deploy"**

### วิธีที่ 2: Deploy ผ่าน Vercel CLI
```bash
npm install -g vercel
vercel
```
